# Wolfram Alpha API Integration

## 1. Описание проекта

Проект представляет собой приложение на Python для интеграции с Wolfram Alpha API.

Программа отправляет запросы к Wolfram Alpha, получает ответы в формате JSON, извлекает полезную текстовую информацию и сохраняет результаты в файлы.

В программе реализовано 15 запросов:
- 10 обязательных запросов согласно заданию;
- 5 дополнительных пользовательских запросов.

## 2. Структура проекта

```text
wolfram_lab/
├── main.py
├── config.py
├── wolfram_api.py
├── parser.py
├── config.json
├── requirements.txt
├── results/
│   ├── raw.json
│   └── parsed.json
└── logs/
    └── app.log
```

Назначение файлов:

- `main.py` — основной модуль, который запускает программу и последовательно обрабатывает запросы.
- `config.py` — загрузка конфигурации приложения.
- `wolfram_api.py` — отправка запросов к Wolfram Alpha API и обработка сетевых ошибок.
- `parser.py` — извлечение текстовых результатов из ответа API.
- `config.json` — хранение AppID для доступа к API.
- `requirements.txt` — список необходимых Python-библиотек.
- `results/raw.json` — полные ответы API.
- `results/parsed.json` — извлечённые результаты запросов.
- `logs/app.log` — журнал работы программы.

## 3. Требования

Для запуска проекта необходимы:
- Python 3;
- библиотека `requests`;
- AppID, полученный на сайте Wolfram Alpha Developer Portal.

## 4. Настройка проекта

1. Установить Python 3.
2. Установить необходимые зависимости:

```bash
pip install -r requirements.txt
```

3. Указать свой AppID в файле `config.json`:

```json
{
    "app_id": "YOUR_APP_ID"
}
```

Вместо `YOUR_APP_ID` необходимо указать полученный AppID.

## 5. Запуск программы

Открыть терминал в папке проекта и выполнить команду:

```bash
python main.py
```

Программа последовательно отправит 15 запросов к Wolfram Alpha API, выведет результаты в терминал и сохранит данные в файлы.

## 6. Обработка ошибок

В проекте предусмотрена обработка следующих ситуаций:
- отсутствие или некорректное содержимое конфигурационного файла;
- превышение времени ожидания ответа API;
- сетевые ошибки и HTTP-ошибки;
- ошибки при разборе JSON;
- неуспешное выполнение запроса Wolfram Alpha.

Информация о работе программы и возникших ошибках записывается в файл `logs/app.log`.

## 7. Результаты работы

После выполнения программы создаются или обновляются следующие файлы:

- `results/raw.json` — полные ответы сервиса Wolfram Alpha;
- `results/parsed.json` — обработанные результаты с текстовыми данными;
- `logs/app.log` — журнал выполнения программы.

## 8. Используемые технологии

- Python 3;
- Wolfram Alpha Full Results API;
- библиотека `requests`;
- формат JSON;
- модуль `logging` для журналирования.
